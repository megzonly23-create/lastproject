LEVEL 16: Seminar Schedule (RowspanAndColspan.html)

Table using rowspan and colspan.

PREVIEW:

CODE:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Seminar Schedule</title>
    <style>
        table {
            width: 80%;
            margin: 20px auto;
            border-collapse: collapse;
            font-family: Arial, sans-serif;
            text-align: center;
        }
        th, td {
            border: 1px solid black;
            padding: 10px;
            vertical-align: middle;
        }
        th {
            background-color: #f9f9f9;
        }
    </style>
</head>
<body>

    <table>
        <!-- Row 1: Main Title -->
        <tr>
            <th colspan="4">Seminar</th>
        </tr>
        
        <!-- Row 2: Sub-headers for Schedule and Topic -->
        <tr>
            <th rowspan="2" style="width: 20%;">Day</th>
            <th colspan="2">Schedule</th>
            <th rowspan="2" style="width: 40%;">Topic</th>
        </tr>
        
        <!-- Row 3: Begin and End sub-headers -->
        <tr>
            <th>Begin</th>
            <th>End</th>
        </tr>
